Jaimin Patel - Single-Page LinkedIn Style Personal Portfolio (v2)
==============================

Package Contents:
-----------------
1. index.html   - Semantic HTML5 web page containing complete, rich content from Jaimin Patel's LinkedIn profile.
2. styles.css   - Modern stylesheet featuring LinkedIn design variables, smooth scroll navigation, keyframe entrance animations, interactive hover states, and a dedicated ATS / Print PDF stylesheet.
3. README.txt   - Documentation and usage instructions.

Key Features & Enhancements:
----------------------------
- Full Rich Content: Includes detailed about section, complete career history across Horizontal Digital (Project Delivery Manager & Associate PM), PMC Retail, Space-O Technologies, Intuz, certifications (CSM® & PMI), projects, recommendations, skills, awards, and community leadership.
- Smooth Single-Page Navigation: Smooth scrolling linking to section IDs with sticky navigation bar and floating "Back to Top" button.
- Animated Transitions: CSS keyframe entrance animations (`slideUpFade`) and micro-interaction hover transforms on cards, badges, and skill pills.
- ATS (Applicant Tracking System) Ready: Built using semantic HTML5 tags (`<main>`, `<header>`, `<section>`, `<article>`, `<aside>`, `<address>`) with strict structural hierarchy.
- One-Click ATS PDF Export: Includes an "Export / Print ATS PDF" button using `@media print` CSS rules. Printing or saving as PDF automatically removes decorative headers/buttons and outputs a crisp, high-contrast resume document that ATS scanners parse seamlessly.

Usage:
------
Extract the zip file to any folder on your computer. Double-click `index.html` to open in any web browser (Chrome, Edge, Firefox, Safari).
